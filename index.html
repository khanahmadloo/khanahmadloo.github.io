Personal Project Apache Spark

Access Log Processing & Analytics Pipeline

Built a structured log analytics workflow with PySpark DataFrame APIs to convert raw web server access logs into queryable columns, validate request data, and answer operational and security-oriented questions without using the RDD API.

Business Problem

Web servers generate large volumes of raw access logs that are difficult to analyze directly. Operations and security teams need structured data to understand traffic patterns, monitor failed requests, identify popular resources, and detect unusually high request activity.

Project Objective

Transform semi-structured web access logs into a structured Spark DataFrame and build reusable analytical workflows for traffic, HTTP status, URL, user-agent, bandwidth, and high-frequency request analysis.

Business Value

Provides structured insights for operational monitoring, traffic analysis, bandwidth visibility, user-agent analysis, and basic security investigation by highlighting abnormal request patterns.

Architecture

Raw Web Server Log
access.log
Spark DataFrame Ingestion
Read raw log lines as a DataFrame
Parsing & Structuring
Regex extraction → ip, timestamp, method, url, status, bytes, user_agent
DataFrame Transformations
select · filter · groupBy · agg · orderBy
Operational & Security Analytics
Traffic, status codes, URLs, user agents, request frequency

What I Implemented

  • Loaded raw Apache-style access logs with Spark DataFrame APIs.
  • Parsed semi-structured log lines into typed, analytics-ready columns.
  • Filtered successful requests with HTTP status 200.
  • Aggregated request counts by IP address and URL.
  • Calculated total transferred bytes and traffic by URL.
  • Analyzed browser and device information from user-agent strings.

Advanced Analysis

  • Identified the successful URL generating the highest traffic volume.
  • Grouped requests by IP address and minute for high-frequency request detection.
  • Flagged IPs exceeding 1,000 requests per minute as a security-oriented analysis scenario.
  • Compared the structured DataFrame approach with the earlier RDD-based implementation.
